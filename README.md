# 🌐 Personal Portfolio Website

This repository houses the source code for my personal portfolio website, hosted via GitHub Pages. It serves as a central hub to showcase my software engineering projects, technical skills, and academic focus.

🔗 **Live Link:** [geleriuadrian.github.io](https://geleriuadrian.github.io)

---

## 🚀 Features

* **Responsive Design:** Optimized for seamless viewing across mobile, tablet, and desktop viewports.
* **Project Showcase:** An interactive space detailing standalone software tools, complete with technical breakdowns and source links.
* **Fast & Lightweight:** Built with minimal overhead to ensure quick load times and high performance.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Hosting:** GitHub Pages
* **Design/Layout:** Flexbox, CSS Grid

---

## 📁 Repository Structure

* `index.html` - The main entry point and landing page.
* `assets/` - Contains images, project screenshots, and visual media.
* `css/` - Custom stylesheets managing layout, typography, and responsive design breakpoints.
* `js/` - Script files handling interactive elements and dynamic behavior.
